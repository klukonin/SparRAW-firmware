# Входы разбора и сборки

Репозиторий приватный: здесь лежат производные вендорских образов, без
которых сборка `4.1/` и `6.2/` не воспроизводится. Сами образы и
board-файлы — в [../images](../images/README.md). Контрольные суммы —
`SHA256SUMS` (`sha256sum -c SHA256SUMS` из этого каталога).

| каталог | что |
|---|---|
| `kit-4100/`, `kit-6200/` | сегменты образов (fw_code 0x8c0000, fw_data 0x900000, uc_code 0x920000, uc_data 0x940000, три AGC) и таблица лог-строк — вход `make tree` |
| `insns/` | полный листинг инструкций обоих образов (Ghidra) — вход инструментов разметки |
| `fwlog-strings/` | таблицы лог-строк 4.1.0.1000 (fw и ucode) |
