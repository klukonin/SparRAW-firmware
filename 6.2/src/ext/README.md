# src/ext — дополнительный код, добавляемый к прошивке

Сюда кладутся модули на C, которые собираются тулчейном ARC и линкуются
в **свободный хвост** `fw_code` (секция `.text.ext`, см. `ld/memory.ld`),
не затрагивая ни одного байта вендорского кода.

Свободно в 6.2.0.1000: fw_code 15004 Б (с 0x8fc564), uc_code 4924 Б.

Вызов вендорских функций — по адресам из `ref/SYMS.txt` через
`ld/symbols.ld` (генерация — `make symbols`).
Встраивание в существующий поток — трамплинами.
