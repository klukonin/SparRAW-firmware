# SparRAW-firmware / 6.2 — прошивка 6.2.0.1000

Сборка 6.2.0.1000 с таблицами лог-строк; телеметрия распределённого биконинга удалена, механизм сохранён. `make fw` даёт вендорский образ побайтово. Здесь ничего не правится: открытая прошивка на основе этого дерева — [../6.4](../6.4/README.md) (блоки на C, патчи quilt к копии дерева).

## Сборка

    make tree      # дерево исходников из дизассемблированного образа (src/asm/{fw,uc})
    make rebuild   # сегменты кода с проверкой
    make fw        # прошиваемый образ build/wil6210-selfbuilt.fw
    make gate      # сверка кодировок ассемблера с образом
    make regs      # карта регистров ref/REGS-62.md

Тулчейн и ключи — [docs/TOOLCHAIN.md](../docs/TOOLCHAIN.md), замена блоков на C/C++ —
[docs/REWRITING.md](../docs/REWRITING.md). Входные образы и сегменты — `../blobs/`
(происхождение — [ref/BLOBS.md](ref/BLOBS.md)).

## Состав

| путь | что |
|---|---|
| `src/asm/fw`, `src/asm/uc` | код по блокам: 2597 блоков fw, 870 блоков ucode; `blocks.json` — адреса и имена |
| `src/data` | сегменты данных |
| `src/ext` | модули поверх вендорского образа (трамплины-хуки) |
| `ld/` | карта памяти и скрипты компоновки |
| `ref/` | данные разметки: имена, символы, аннотации, таблицы строк, карты |
| `tools/` | генераторы дерева, проверки, стендовые скрипты |
| `docs/` | документы только по этой версии; общие — в [../docs](../docs/README.md) |

Свободный хвост под новый код: fw 0x8fc564–0x900000 (15 004 Б), ucode 0x93ecc4–0x940000 (4 924 Б).
