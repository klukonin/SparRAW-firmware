# Прочие области fw и ucode 4.1

Поблочный справочник по функциям 4.1, которые не вошли в тематические документы: РЧ и
калибровки, тракт данных fw и ucode, PCIe и питание, соединение и PS, остаток BF/BRP/TXSS,
почтовые ящики fw↔ucode, вектора и загрузка, скан и discovery, планировщик и BI/AW,
радио-менеджер, PS в ucode, каталог мелких блоков. Устройство подсистем, общее для 4.1 и
6.2, — в [docs/HW-DRIVERS.md](../../docs/HW-DRIVERS.md) и других документах `docs/`; здесь —
перечень блоков 4.1 с адресами и ролями.

Метки: **[код]** — по листингу; **[стр]** — роль по собственным лог-строкам функции;
**[выз]** — роль по вызовам и соседям. Адреса без пометки — fw, с пометкой `uc` — ucode.

## Глубина описания

Описание 4.1 складывается из четырёх источников разной глубины:
* ~70 КБ — перенос из 6.2 по одноимённым функциям ([CROSS-VERSION.md](../../docs/CROSS-VERSION.md):
  класс A 39 КБ — общие лог-строки, B 28 КБ — совпадают имя и размер, C 3 КБ — требуют
  сверки); тела 4.1 не читались;
* 3,4 КБ — обработчики автоматов по вендорским таблицам ([STATE-MACHINES.md](../../docs/STATE-MACHINES.md));
* ~61 КБ — разделы 1–13 этого документа: имена 4.1 из собственных лог-строк плюс строки и
  соседи, отдельные места **[код]**;
* 7,4 КБ — раздел 14, каталог (битовые поля, фрагменты, аксессоры) без чтения тел.
