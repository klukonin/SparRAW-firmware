# Прошивка 6.4 mesh: DMG IBSS

Вариант прошивки `mesh` — только DMG IBSS по 802.11-2020 (11.1.3.5 маяки, 11.1.5 TSF,
10.42.6 обучение луча в DTI). Узлы ячейки связываются без ассоциации, сами, без действий
хоста. Метки: **[код]**, **[стандарт]**, **[железо]** — проверено на стенде из двух узлов
(29.09.2026).

## 1. Итог на стенде **[железо]**

* Два узла, штатные параметры драйвера (без `oob_mode`, `roleless_link`), `iw ibss join`:
  связь поднимается сама; ping 0,6–10 мс (среднее ≈ 1,2 мс), iperf3 ≈ 900 Мбит/с в обе
  стороны.
* Маяки обоих узлов несут настоящий Timestamp, TSF и сетка TBTT общие (11.1.5).
* Сосед выключен — снимается за 3–6 с, хост получает `WMI_DISCONNECT_EVENT`; включён —
  узлы связываются заново.

## 3. Находки

* **Метка времени маяка — состояние железа.** До первого обучения луча с соседом (у любой
  роли, даже у точки AP до первой станции) DMG Beacon уходит с Timestamp = 6; после — с TSF.
  Состояние переживает перезагрузку прошивки драйвером (`wil_target_reset` не трогает биты
  0..8, 19, 20 `SW_RST_VEC_0`), снимается только питанием. 0x886ba4 (только чтение) —
  метка последнего своего маяка. Программного полного сброса чипа не найдено; PCIe reset
  через sysfs (`flr`, `bus`) оставляет модуль мёртвым до снятия питания.
* **Адреса.** В DMG Beacon одно адресное поле — BSSID; у IBSS он общий, индивидуальный
  адрес члена — в DMG Capabilities (9.3.4.2, 9.4.2.127). A-BFT по стандарту только у AP/PCP
  (10.42.5); между членами IBSS — SLS в DTI (10.42.6). Штатный захват линка 6.2
  (`find_main_sm__bcon_args`) это и делает; ответчик в режиме PCP заводит соединение сам.
* **Калибровка.** Пока у узла нет соединения, калибровка выключает/включает приём
  (LMAC 0x3/0x1) каждые 20–100 мс; после соединения затихает.

## 4. Ячейки для отладки (данные ucode, хост 0x943a48 + смещение)

| смещение | что |
|---|---|
| 0x04 | `ibss_uc_state`: T_BTI, BTI с развёрткой, отменено, последняя задержка |
| 0x28 | управление: 0x1b5c0000 \| бит 0 без задержки, бит 1 штатная развёртка |
| 0x2c | `ibss_tsf_state`: valid, маяков ячейки, принято TSF, последняя разность, запусков SLS, снято соседей |

## 5. Не сделано

* Больше двух узлов в ячейке на стенде не проверено (код ведёт соседей по CID, до 8).
* Энергосбережение IBSS (ATIM, 11.2.4) — выключено принудительно.
* Метка времени у узла, ни разу не обучавшего луч, остаётся 6 до первого SLS: первый
  TSF ячейки узел может принять только после связи.
